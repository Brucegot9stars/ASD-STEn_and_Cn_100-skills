# 受控中文词表（禁用词、替换词、一词一义）

用法：改写时先查本表。表里没有的词，按"一个概念只用一个词"自建项目术语表。
"自动检查"为 **是** 的条目已内置在 `scripts/check_zh.py` 中。

本表是**通用技术写作的起步表**，不覆盖具体行业术语。行业词（如 `热交换器`、`熔断`）由项目术语表管理。

## 7. 易混动词搭配

| 场景 | 用 | 不用 |
|---|---|---|
| 文件、窗口 | 打开 / 关闭 | 启用 / 停用 |
| 功能、开关项 | 启用 / 停用 | 打开 / 关闭 |
| 服务、进程、容器 | 启动 / 停止 | 打开 / 关闭 |
| 电源、气源、液压 | 接通 / 断开 | 启动 / 停止 |
| 会话、连接 | 建立 / 断开 | 打开 / 关闭 |
| 端口、通道 | 开放 / 关闭 | 启用 / 停用 |
| 日志、缓存 | 清理 | 删除（删除是移除文件） |

## 9. 情态与程度

| 不批准 | 批准 | 说明 |
|---|---|---|
| 可以（表能力） | 支持 | 消除许可/能力歧义 |
| 应 / 应当 / 须 / 务必 | 必须 | 统一为最强一档 |
| 需要（表要求） | 必须 | "需要"也表示"缺少"，易混 |
| 最好 / 宜 / 不妨 | 建议 | 统一为推荐一档 |
| 非常 / 十分 / 较为 / 相当 | 删除，或给量化 | 程度副词不提供信息 |
| 基本上 / 大致上 | 删除，或给数值 | 同上 |

## 维护方式

1. 新增词条写清四项：词、意义、处理方式（禁用 / 选词 / 限定）、一个例句。
2. 改完词表同步改脚本内置表，再跑一次样例，确认无误报。
3. 行业术语不进本表，进项目术语表，并注明来源（图纸、标准、官方文件）。
