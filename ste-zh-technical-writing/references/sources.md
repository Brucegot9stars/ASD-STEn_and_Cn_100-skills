# 来源、校准依据与边界

## 1. 方法来源：ASD-STE100

- 标准全称：**ASD-STE100 Simplified Technical English**，当前版本 **Issue 9，2025-01**。发布方为 ASD（AeroSpace and Defence Industries Association of Europe），由其下属 **STEMG**（Simplified Technical English Maintenance Group）维护。
- 结构：53 条写作规则（9 节）+ 受控词典（约 900 个批准词，约 1200 个不批准词及替换建议）。
- 官方入口：<https://www.asd-ste100.org/>。ASTM 亦以 **ASTM F3349** 发布同源标准。
- **只有英文版**。标准正文、词典、规则均为英文，不提供中文版本，也不对中文文本作合规判定。

本 skill 借用的是 STE 的**方法**，不是它的条文：

| STE 的做法 | 中文对应做法 | 差异原因 |
|---|---|---|
| 受控词典，一词一义一词性 | 选词表 + 一词一义 | 中文没有词性屈折，但同义轮换更严重 |
| 名词簇 ≤ 3 词 | 定语 ≤ 3 层 | 中文修饰语全部前置，层数更难解析 |
| 程序句 ≤ 20 词，描述句 ≤ 25 词 | 操作句 ≤ 30 字，描述句 ≤ 40 字 | 按中文语料重新校准 |
| 只用不定式、祈使式、三种时态 | 体标记克制（`了 / 着 / 过`、`正在`、`将会`） | 中文无时态，靠体标记和时间词 |
| 禁 `-ing` 动词形式 | 不用"进行 / 加以 + 动词" | 中文的名词化机制 |
| 程序用祈使句、主动语态 | 动词开头、去 `被` 字句、去"由……进行" | 相同 |
| `WARNING` / `CAUTION` / `NOTE` | `警告` / `注意` / `说明` | 三级划分对应 |
| 不用分号 | 不用分号 | 相同 |
| 不用 `e.g. / i.e. / etc.` | 不用"等"作开放列举 | 相同的"开放集合"问题 |

## 2. 阈值校准依据

30 字 / 40 字不是估的，取自中文技术文档的真实分布：

- 参照公开项目 **Simplified Technical Chinese（STC）** 的校准做法。
- 语料是约 **350 万字**中文技术文档，含 8 个开源项目、2856 个文件。
- 统计句长分布后取 **90 分位**。
- 结果：90% 的操作句不超过 **33 字**，90% 的描述句不超过 **41 字**。本 skill 取整为 **30 / 40**，留出余量。
- 严格档 20 / 30 字，用于航空、医疗、高压、化工等读者在压力下执行、读错即出事故的场景。这一档是本 skill 的保守取值，没有语料校准支撑，属于工程判断。

STC 项目地址：<https://github.com/mzopedia/simplified-technical-chinese>。其规范与词表以 CC BY 4.0 发布，检查脚本以 MIT 发布。本 skill 只引用其公开的方法与校准结论，规则文本、词表、脚本均为自写。

另有独立实现可交叉参考。jxxy.net 的《为什么 AI 的技术文档这么难读以及解法》（2026）给出 46 条中文规则、9 章结构。其分节方式与本 skill 接近，可作为第三方佐证。

## 3. 与中文排版规范的关系

受控中文只管**句子和用词**，不管排版和文档结构。两者互补，不要互相替代。

| 项目 | 管什么 | 与本 skill 的关系 |
|---|---|---|
| `ruanyf/document-style-guide` | 标题、段落、数值、标点、文档结构 | 互补，排版交给它 |
| `yikeke/zh-style-guide` | 语言风格、标点、文档元素 | 互补 |
| `Fengng/Tech-Doc-Style-Chinese` | 事实保真、改写流程、术语排版 | 互补，本 skill 补编号规则与受控词表 |
| GB/T 15834 | 标点符号用法 | 本 skill 的标点规则以其为基础，另加"不用分号"的受控约束 |
| GB 3100 至 GB 3102 | 量和单位 | 数值、单位写法依据 |

## 4. 与英文版 skill 的分工

| 场景 | 用哪个 |
|---|---|
| 英文手册、工卡、SOP | `asd-ste100-technical-writing` |
| 中文手册、工卡、SOP | 本 skill |
| 中译英之前的源文简化 | 本 skill，再交翻译 |
| 英译中之后的译文校对 | 本 skill 查可读性，另需双语对照查技术含义 |
| 需要声称"符合 ASD-STE100" | 两者都不行。STE 只对英文作合规判定，且需官方审核 |

## 5. 已知局限

- 词表约 110 条，只覆盖通用技术写作。行业术语必须由项目术语表补齐。
- 没有做过阅读理解对照实验。校准量的是句长分布和误报率，不是读错率。
- 脚本只做模式匹配，不解析句法树。定语层数、指代唯一性、术语是否选对，脚本查不出。
- 严格档阈值（20 / 30 字）是工程判断，未做语料校准。
- 中文技术写作没有官方受控标准。本 skill 是**非官方**写作辅助，不隶属 ASD、STEMG 或上述任何项目，不构成合规认证，也不替代工程评审。
