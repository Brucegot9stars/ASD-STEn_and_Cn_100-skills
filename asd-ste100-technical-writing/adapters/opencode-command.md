description: 按 ASD-STE100 改写或检查英文技术文档
---

按 ASD-STE100 Issue 9 的写作规则处理下面的任务。先读 `references` 目录下 writing-rules.md 的第 3 节，需要选词时读同目录的 vocabulary-and-grammar.md。

任务与目标文件：$ARGUMENTS

执行步骤：

1. 判定文本类型：程序 / 描述 / 安全说明 / 混合。默认目标版本 Issue 9。
2. 列出不可改内容：代码、命令、路径、标识符、错误串、数字、单位、版本、UI 标签、法规原文。
3. 建术语表：技术名词与技术动词各定唯一写法。
4. 分层改写：词 → 名词簇 → 动词 → 句子 → 段落 → 安全说明 → 标点。
5. 运行 `python scripts/check_en.py <文件>`，清掉全部【必须】级发现。若用户只要检查，跳过改写直接给报告。
6. 复核技术含义、条件、例外、单位、失败处理是否仍在。
7. 输出改写稿、变更说明表（Before | After | 规则 | 理由）、待确认清单。

不要改代码块与行内代码。不要新增原文没有的数值或条件。不要虚构词典批准状态。不要写"通过 ASD-STE100 认证"。中文段落请用 `ste-zh-technical-writing`。
