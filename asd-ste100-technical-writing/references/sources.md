# 权威来源与版本信息

## 1. 核心事实

| 项目 | 事实 |
|---|---|
| 标准全称 | ASD-STE100 Simplified Technical English |
| 副标题（Issue 9 起） | Standard for Technical Documentation |
| 当前版本 | **Issue 9，2025 年 1 月 15 日** |
| 上一版本 | Issue 8，2021 年 4 月 30 日 |
| 下一版本 | Issue 10，计划 2028 年 1 月（通常三年一版） |
| 结构 | 53 条写作规则（9 节）+ 受控词典 |
| 词典规模 | 约 900 个批准词；约 1200 个不批准词及替换建议 |
| 规则节数 | 14 / 3 / 7 / 4 / 5 / 6 / 3 / 7 / 4 = 53 |
| 关键限制 | 程序句 ≤ 20 词；描述句 ≤ 25 词；段落 ≤ 6 句；名词簇 ≤ 3 词 |
| 技术术语 | Issue 9 起用 technical nouns / technical verbs；技术名词 22 类，技术动词 4 类 |
| 词典精确计数 | Issue 9 常被引为 875 个批准词、1,274 个不批准词；官方概述为约 900 / 约 1,200 |
| 规则构成 | 53 条写作规则 + 8 条 general recommendations（GR-1–GR-8，性质为建议，不计入 53 条） |
| 维护机构 | ASD Simplified Technical English Maintenance Group（STEMG），隶属 ASD |
| 版权 | ASD 所有；欧盟商标号 017966390 |
| 获取方式 | Issue 6（2013）起免费，通过 asd-ste100.org 申请 |
| 历史节点 | 1979 年航空公司提出需求；1983 年 STEMG 成立；1986 年首版 AECMA Guide；2004 年 AECMA 并入 ASD；2005 年改名 ASD-STE100；2025 年升为国际标准 |

## 4. 相关规范

- **ATA iSpec 2200**（原 ATA 100）：1986 年起要求 STE。
- **ATA 104**：培训规范，要求 STE。
- **S1000D**：推荐 STE；许多项目通过业务规则强制。
- **EDSTAR**：欧洲国防标准参考，推荐 STE。
- **EASA / FAA / CAAC**：持续适航指令中要求 STE。
- **ISO 24620-4:2023**：语言资源管理，引用 STE。

## 5. 引用规范

推荐写法：

> ASD-STE100 Simplified Technical English, Issue 9, January 2025, ASD Simplified Technical English Maintenance Group (STEMG), Brussels.

或：

> 按 ASD-STE100 Issue 9 的写作规则改写。

不要写：

- "通过 ASD-STE100 官方认证"
- "完全符合 ASD-STE100"
- "ASD/STEMG 推荐工具"
- "STE 认证文本"

原因：ASD/STEMG 不认证工具、不认证文本、不背书第三方；合规判断需要完整核对标准与词典。

## 6. 使用边界

- 本 skill **不包含完整词典**，不能逐词判定批准状态；关键用词必须查 Issue 9 官方 PDF。
- 本 skill 的规则编号中，标 † 的示例来自公开培训/研究材料，引用前核对原文。
- 行业采用数据（如 64% 非航空国防用户）来自 Issue 8 分发统计，随时间变化。
- 本 skill 是写作辅助，不替代工程评审、法规审查、翻译审校。
- 标准版权归 ASD；本 skill 只做摘要与改写方法，不复制标准正文。
