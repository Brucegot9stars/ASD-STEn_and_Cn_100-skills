# Lubrication Procedure

Prior to carrying out the lubrication procedure, ensure that the power supply has been isolated; the technician should then wear protective gloves.

The system has been tested and it's running smoothly; users cannot replace the battery, i.e. the pack must be returned to an approved service station.

CAUTION: EXTREME CLEANLINESS OF OXYGEN TUBES IS IMPERATIVE.

NOTE: Make sure that you disconnect the connector before you remove the cover.

You should set the TEST switch to the middle position and release the SHORT-CIRCUIT TEST switch, if the indicator is off.

The forward turbine overheat thermocouple terminal tags are installed on the panel.
