# Lubrication Procedure

WARNING: DO NOT TOUCH THE EXHAUST DUCT. THE SURFACE IS HOT AND CAN CAUSE BURNS.

Prerequisites: The power supply is off. You have protective gloves.

1. Disconnect the power supply.
2. Put on protective gloves.
3. Lubricate the bearing.
4. Do the test of the system.
5. Set the TEST switch to the middle position.
6. Release the SHORT-CIRCUIT TEST switch.

NOTE: The test takes about 5 minutes.
